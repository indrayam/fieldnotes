Skill explainer · jgraph/drawio-mcp

Draw.io

Every diagram becomes a native .drawio file first, then whatever format you asked for.

The official draw.io skill, shipped byte-identical to Claude Code, Codex, Copilot, Cursor and Antigravity. Author as Mermaid or XML, repair it, lay it out with ELK, and export with the XML embedded so every PNG stays editable. I read the skill, ran both servers’ test suites and the shared modules. Every diagram becomes a native .drawio file first, then is delivered in the requested output format, whether you authored Mermaid or XML.

Who it is for

Agents in terminals (Claude Code, Codex, Copilot CLI) where diagrams cannot render inline.

What you get

A .drawio, an embedded-XML PNG/SVG/PDF, or an app.diagrams.net link.

How It Works

Author, Repair, Lay Out, Deliver

The skill is one pipeline with two ways in.

1

Inline first. Inline viewer first. In chats that render diagrams, the MCP create_diagram tool wins.

2

Author. Prefer Mermaid for the standard types above. Use XML for precise control, or when nothing can convert Mermaid. PNG, SVG and PDF need the desktop CLI either way.

3

Repair. It changes nothing in a well-formed file, and needs only Node.js.

4

Lay out. The CLI's --layout step auto-positions XML-authored diagrams with the same ELK layouts as the editor's Arrange ▸ Layout menu and the draw.io MCP app server.

5

Deliver. Exports use double extensions so the name says the XML is inside.

Shapes, Icons And macOS (1.2.6)

Look Up Icons, Find The Real Binary

New in plugin 1.2.6. Both fixes stop the agent from guessing.

1

Icon lookup. never guess mxgraph.* names: look them all up in one call to scripts/find-shapes.js in this skill's folder (Node.js 18+, network), one query per icon, narrowed by library (aws4, azure2, cisco19). Why: a wrong stencil name renders as an empty box, and this works without the MCP server.

2

Output. prints title width×height style lines; use a style as is:

3

macOS CLI. this prints the first of drawio on PATH (Homebrew), /Applications, the per-user ~/Applications and Spotlight, or nothing if draw.io is absent:

4

Use the real binary. Call the binary inside the .app: a copy or symlink outside it dies with Unable to find helper app.

5

File naming. The File naming section no longer tells you to delete the .mmd or intermediate .drawio; the workflow steps above it still do.

6

MCP icon=name (not the plugin). Plugin 1.3.1. On the MCP servers at a7d1ead, a vertex style can name an icon instead of guessing an mxgraph.* stencil: icon=aws lambda (~1,750 AWS/Azure/GCP/K8s). Shipped in tool-server 1.13.0 and app-server 1.10.0; create_diagram and open_drawio_xml expand it. The plain CLI does not. Upstream source, not runtime-tested here; see Servers.

node <skill-folder>/scripts/find-shapes.js "aws4 lambda" "github" "slack"

# macOS: which draw.io will the skill use?

App Server 1.10.0 And Tool Server 1.13.1

Icons By Name, Table Shorthands, Connector Check

Read from upstream source at a7d1ead. Plugin 1.3.1. Neither server was installed or test-run on this box.

1

PNG/SVG from the viewer (app-server 1.9.0). Copy the diagram XML; download it as a .drawio file, PNG or SVG and copy it as a PNG or SVG where the host allows it. Copy as SVG writes what draw.io's does.

2

Icons by name (tool-server 1.13.0, app-server 1.10.0). icon=aws lambda in a vertex style stands for the official icon of that service (~1,750 AWS, Azure, GCP and Kubernetes icons). Write icon=aws lambda, icon=azure functions, icon=gcp pub sub, or icon=kubernetes pod; the resolver fills in the official style. Expanded in MCP create_diagram and open_drawio_xml; the plain CLI does not expand them. Upstream source only — not runtime-tested here.

3

Table-row and role XML (app-server 1.10.0). rows="PK id|FK author_id|title" expands into stacked table cells. role=step, decision, start, end, error, data, plus external and container, pick the calm-theme shape and color. Expanded in MCP create_diagram (and the viewer on the tool input); the tool server, the skill and the plain CLI do not. Upstream source only — not runtime-tested here.

4

Connector layout check. one line per connector with everything found on it. This pass moves such a waypoint onto the connection point's line when it sits less than 3 px off a fixed port, so the router adds no jog at the shape.

5

Self-hosted / link only. Set DRAWIO_BASE_URL to a self-hosted draw.io. Set DRAWIO_BROWSER to off to get only the URL. The layout-fix chip remains: the toolbar shows a chip, "Fix N issues".

Gap Mermaid, layouts and export all need the desktop app

Without it the skill can only write XML and a URL. The skill says so and falls back cleanly.

Gap References load from main, unpinned

SKILL.md tells the agent to fetch xml-essentials.md and mermaid-reference.md from raw.githubusercontent.com/…/main, so a skill pinned at one commit reads rules from another.

Cost Two repair implementations

The inline one-liner and repair-xml.js do overlapping work; only the module reports what it changed or handles leaked tool-call tags.

Bug Shape search ranks a number first

“cisco router” returns a stencil titled “10700” above “ATM Router”.

Copy Editable exports

-e embeds the XML, and the double extension tells people it is there.

Copy Port parity in CI

One workflow fails the build if any port’s SKILL.md drifts from the Claude Code copy.

Build Your Own

What To Steal

  1. One native artifact, many deliveries. Write the source format first; derive the rest.

  2. Prefer a layout engine to model coordinates. Ask for structure, not positions.

  3. Measure the model’s mistakes, then fix them in code. repair-xml.js says its three fixes covered all 15 broken diagrams out of 473.

  4. Detect the environment exhaustively. The Windows chain checks PATH, install paths, registry and other drives before giving up.

  5. Keep ports identical by CI.
