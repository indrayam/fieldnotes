Excalidraw

An agent draws on a live canvas, then screenshots its own work and fixes what it sees.

A skill, a CLI and an MCP server over one Excalidraw canvas. I read the skill and cheatsheet, ran the test suite, and drove every local CLI command against a private server. Pairing describe with screenshot is what makes this skill powerful.

How It Works

Plan The Grid, Draw, Screenshot, Fix

From SKILL.md.

1

Pick an interface. Three interfaces drive the same live canvas. Pick the first one that applies:

2

Plan. Plan your coordinate grid — map out tiers and x-positions before writing JSON.

3

Check every batch. After each add / apply / batch_create_elements, take a screenshot and check:

4

Say it out loud. If you find any issue: stop, fix it, re-screenshot, then continue.

5

No browser for checks. Screenshots and image exports render headless inside the canvas server, so you never need a browser tab to check your own work.

What I Found Running It

Solid And Well Tested; A Few Sharp Edges

Run on a copy in /tmp with nice and timeout; the server ran on port 3917 and I stopped it by its own pid.

RunResultNote
npm test (6 suites)passstdio wire 5/5, local bind, 25 render checks, state, durable state, share URL.
CLI session16 commandsAll behaved as documented.
mermaid with no tabexit 4As documented.
export to a missing directoryexit 1ENOENT; no mkdir.

Copy Headless verification

Screenshots render in the server with Excalidraw’s own renderer; the agent never needs a browser to see its work.

Copy Exit codes as an API

0 ok, 1 error, 2 usage, 3 canvas unreachable, 4 browser needed. Destructive clear needs --yes (exit 2 otherwise).

Copy Safe stop

stop checks /health identity and only signals its own server.

Gap Export does not create directories

A path inside a missing folder fails with ENOENT.

Gap Mermaid needs a browser tab

Conversion runs in the frontend, so headless agents cannot use it.

Cost Element counts drift

add and snapshot report 8 elements; export reports 12, because bound label text becomes separate elements. SKILL.md’s duplicate-text section covers the related auto-sync issue.

Cost share uploads

share sends an encrypted scene to excalidraw.com unless self-hosted URLs are set. I did not run it.

Build Your Own

What To Steal

  1. One canvas, three interfaces. MCP, CLI and REST map 1:1.

  2. Text plus pixels. describe for ids, screenshot for quality.

  3. A written checklist. Seven checks after every batch.

  4. Name the anti-patterns. Zone labels, cross-zone arrows and label spam, each with a fix.
