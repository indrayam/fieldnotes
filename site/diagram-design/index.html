Skill explainer · cathrynlavery/diagram-design

Diagram Design

Fifty editorial diagram types, one rule above all: delete until nothing can be removed.

A Claude/Cursor skill that writes self-contained HTML with inline SVG in a skinnable editorial system. It routes a request through 9 semantic patterns to 50 type references, ships importers for draw.io, Excalidraw, Mermaid and PlantUML, and backs its charts with geometry verifiers. I read the skill at f6db0de, ran plantuml_extract.py on the shipped fixtures and verify_geometry.py --all (239 assets, 0 findings). The highest-quality move is usually deletion.

Who it is for

Anyone who wants a diagram that looks designed rather than generated: architecture, charts, journeys, maps.

What you get

One HTML file per diagram, optional SVG/PNG export, and a brand profile you can save and reload.

How It Works

It Picks A Pattern, Then A Type, Then Asks

The skill is a router. Behavior picks the pattern, the pattern picks the nearest layout, and the plan is confirmed before anything is drawn.

1

Style gate. If they are still the shipped defaults (paper #f5f5f5, ink #2d3142, accent #bf4520), pause and ask the user.

2

Semantic pattern. When behavior, state, enforcement, or risk carries the meaning, first load semantic-patterns.md.

3

Visual type. Always load the chosen type reference linked in the guide before drawing.

4

Confirm. Before rendering, state the plan in one short message: the chosen visual type (and semantic pattern, if routed), the size preset, and anything the complexity budget (§7) will force out.

5

Density. Target density: 4/10. Enough to be technically complete. Not so dense it needs a guide. Above 9 nodes, it's probably two diagrams.

Taste

It Names The Slop It Refuses To Make

The universal anti-patterns from SKILL.md §4, verbatim.

Anti-patternWhy it fails
Dark mode + cyan/purple glowLooks "technical" without design decisions
JetBrains Mono as blanket "dev" fontMono is for technical content — ports, commands, URLs. Names go in Geist sans.
Identical boxes for every nodeErases hierarchy
Legend floating inside the diagram areaCollides with nodes
Arrow labels with no masking rectBleeds through the line
Vertical writing-mode text on arrowsUnreadable
3 equal-width summary cards as defaultGeneric grid — vary widths
Shadow on any elementShadows are out. Borders are in.
rounded-2xl on boxesMax radius 6–10px or none
Coral on every "important" nodeCoral is 1–2 editorial accents, not a signaling system
Reproducing Mermaid's renderer layoutImports automatic spacing and routing instead of making an editorial layout

Gap Verifier flags disagree

Most verifiers take --all; verify-motion takes --shipped and rejects --all. Without a flag they print usage and exit 2, which reads like a failure in CI.

Gap Playwright is a silent prerequisite

Three tests and PNG export need a downloaded Chromium. The export command documents this; the test scripts just crash with a stack trace.

Gap Version drift

plugin.json says 2.6.164; SKILL.md metadata says 2.6.

Bug Escaped IR headers

drawio_extract and excalidraw_extract print the file name markdown-escaped (sample\-architecture\.drawio); mermaid_extract does not.

Copy Untrusted-input stance in parsers

The Excalidraw and Mermaid extractors treat labels as data and discard links and payloads. That is the right default for anything an agent reads.

Copy Verifiers for the chart math

Waterfall, Sankey, beeswarm and others check the rendered geometry against declared values, so a plausible-but-wrong chart fails.

Build Your Own

What To Steal

  1. One reference file per output type. Each has Best for, layout rules and anti-patterns. The agent loads only the one it needs.

  2. Route by meaning before layout. A semantic pattern picks the behavior; the type picks geometry.

  3. Gate on brand tokens. Refuse to ship defaults into a branded project without asking.

  4. Confirm the plan in one message. Type, size and what the budget cuts, before drawing.

  5. Ship the checker. self_check.py lets the agent verify its own file.
