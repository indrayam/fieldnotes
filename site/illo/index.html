Illo

A recurring mascot performs the idea; the look and palette are just parameters.

An agent skill for editorial illustrations. One character pack carries one of 17 looks, a palette resolves on top, and a Python engine renders through a subscription CLI, OpenRouter or the agent’s own image tool. I read the skill, ran the 121-test suite and every engine subcommand. This is a configurable house style, not a generic image generator.

Who it is for

Writers who want a consistent illustrated voice across posts, decks and docs.

What you get

One image per idea: an editorial scene, an explainer diagram, a mini-comic or a transparent cutout.

How It Works

The Method Is Constant; The Pack Is The Parameter

Five registers share one workflow: preflight, read and clarify, resolve the character, resolve the palette, generate reference-locked.

1

One idea per image. One image explains one idea: a key judgment, a flow, a before/after, a trap, a loop.

2

The mascot is the subject. A recurring mascot is the one performing the idea in every scene — the subject, never decoration.

3

Look travels with the pack. a character pack carries its style with it.

4

Explainers are pack-solved. A named pipeline or recipe is labeled stages inside that register — named phases in order, one connected system, pack-solved for this body, never a new look.

5

Keys are the user’s. Entering an API key is something the user does.

Bug keyout hard-codes its backend

The record keyout writes always says "backend": "muse-native", so a Grok Bot cutout is mislabeled in the manifest and gallery.

Bug diagram_route.py has no --help

It treats every argument as a request, so --help prints “editorial editorial default”.

Gap Agent-side paths are prose, not code

The Grok Bot and Muse native flows live in SKILL.md; the engine only refuses them and records afterward.

Cost packs list needs the network

Listing community packs fetches the remote repo on every call.

Copy Paid fallback is opt-in

--allow-paid-fallback must be set before a subscription failure can spend OpenRouter credits.

Copy Executable routing oracle

diagram_route.py parses composition.md and is tested against it, so the prose and the code cannot drift.

Build Your Own

What To Steal

  1. Separate method from parameters. Character, look and palette are swappable files; the workflow never changes.

  2. Make identity a technique. Riso is grain, offset and flat fills, not a color, so any palette still reads as the house style.

  3. Anchor sets on the first good image. Every later render references the first one that passes the quality bar.

  4. Write a manifest line per render. Galleries, comparisons and audits come for free.

  5. Keep keys with the user. The agent runs init only for keyless native transports.
