Pretty Mermaid

A thin CLI wrapper around the beautiful-mermaid library: Mermaid in, themed SVG / PNG / Unicode out, no browser.

The skill is a 204-line SKILL.md plus four Node scripts. render.mjs renders one file, batch.mjs a directory, themes.mjs lists themes, png.mjs rasterises SVG with resvg. Layout and drawing are done by the beautiful-mermaid npm package (^1.1.3), not by Mermaid.js, so no headless Chromium is involved. It supports six diagram types, not all of Mermaid.

15built-in themes (node scripts/themes.mjs; THEMES from beautiful-mermaid)
6diagram types: flowchart, sequence, state, class, ER, xychart (SKILL.md L33–44)
3output formats: svg, png, ascii (Unicode, --use-ascii, ANSI via --color-mode) (L46–54)
2runtime deps: beautiful-mermaid ^1.1.3, @resvg/resvg-js ^2.6.2 (package.json)
passnpm test: "6 diagrams x 3 formats, 15 themes" smoke test; npm run validate: docs valid
1verified bug: color flags are silently dropped when --theme is set (render.mjs L204)

Bugs found

1

Theme + colors. SKILL.md L119: "A named theme can be refined with explicit color flags." The code says otherwise: render.mjs L204 const colors = theme || {bg, fg, …}, same in batch.mjs L208. With a theme, the flags never reach the renderer. Checked: SVG output with -t tokyo-night and with -t tokyo-night --bg '#ff0000' had the same md5. Fix is a spread: {...theme, ...custom}.

2

ASCII palette. customColors for ASCII (L186) ignores --muted and --surface, though the flags parse.

3

"Workers". Not parallel processes, just batches awaited with Promise.allSettled (batch.mjs L84–87). Fine for I/O, no CPU gain.

4

ASCII junctions. Flowchart branch from a diamond draws │ ├─Yes with a stray vertical; cosmetic, from beautiful-mermaid uncertain.

5

Line count drift. validate-docs reports 205 SKILL lines; wc -l gives 204 (trailing-newline counting). Harmless.

Side effects

Side effects

1

Auto npm install. If beautiful-mermaid is missing, render.mjs runs npm install in the skill dir via execSync (L33–59): network plus writes to node_modules, without asking. node_modules was already present here.

2

Overwrites. The script writes --output unconditionally; the "do not overwrite" rule (SKILL L31) is on the agent, not enforced.

3

Fonts. SVG asks for Inter by name; if the viewer lacks it, the fallback font changes text widths uncertain.
