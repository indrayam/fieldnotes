# Agent guidance

Read `README.md` before changing or building this site. It is the detailed reference for the repository layout, source checkouts, build commands, and deploy process.

## Shared editing

- Before starting work, run `git pull --rebase origin main` to include changes from the other editor, Grok Bot.
- Keep commits small. Never force-push.
- Keep work inside this docs repository. Do not change the sibling indrayam.com sites.

## Sources and generated pages

- `site/` is the deployed output. Commit generated output along with its source changes; Vercel does not build the site.
- For generated explainers, edit their source under `build/` and rebuild the relevant page with `python3 build/build.py <slug>`.
- `site/index.html` is generated by `build/site_index.py`. For a lasting homepage change, update the builder and rebuild with `python3 build/build.py index`.
- If the user explicitly asks for a direct edit to `site/index.html`, preserve that edit and do not rebuild the homepage until the change has been carried into `build/site_index.py`. Tell the user this coordination step is needed before a later rebuild.

## Content boundary

- Never add internal Cisco material, including `ai-native-assessment`, `ai-harness-setup`, or other work content. The build includes a check for this.
