Matt Pocock skills

One explainer per skill from github.com/mattpocock/skills, read at commit 5beb35b, with notes on pairing each with pstack.

  • mattpocock/grill-with-docs

    October 23, 2026

    A relentless design interview that writes a glossary and ADRs as you go. Two lines that load grilling and domain-modeling.

  • mattpocock/wayfinder

    October 23, 2026

    Plans work too big for one session as a map of decision tickets on your issue tracker, resolved one ticket per session.

  • mattpocock/to-spec → to-tickets

    October 23, 2026

    Turns a finished conversation into a published spec, then a graph of tracer-bullet tickets that implement-spec builds.

  • mattpocock/handoff

    October 23, 2026

    Compacts a conversation into a temp-folder note a fresh agent can pick up, with suggested skills and links instead of copies.

  • mattpocock/setup-matt-pocock-skills

    October 23, 2026

    A one-time interview that tells the engineering skills where your tracker, triage labels and glossary live.

Storytelling Skills

Skills for diagrams, illustrations and visual explanation.

  • Diagram Design

    October 20, 2026

    An agent skill that draws diagrams as one self-contained HTML file with hand-placed inline SVG in a strict editorial style. 45 types shown.

  • Illo

    October 20, 2026

    Turns an idea into an editorial illustration, labelled explainer or transparent cutout, with pixels from an external image model.

  • Draw.io

    October 20, 2026

    jgraph’s draw.io skill: one SKILL.md shared across four agent plugins, backed by the draw.io MCP servers.

  • Pretty Mermaid

    October 20, 2026

    Renders Mermaid diagrams to themed SVG/PNG with the beautiful-mermaid package. No headless browser needed.

  • Excalidraw

    October 20, 2026

    An MCP server plus skill: a live Excalidraw canvas, REST and WebSocket sync, and headless PNG/SVG export.
