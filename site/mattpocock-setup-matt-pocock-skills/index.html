mattpocock/setup-matt-pocock-skills

A one-time interview that writes docs/agents/*.md so the engineering skills know your tracker, labels and glossary.

Configure this repo for the engineering skills: set up its issue tracker, triage label vocabulary, and domain doc layout. Run once before first use of the other engineering skills. This is a prompt-driven skill, not a deterministic script.

Who it is for

Anyone about to use wayfinder, to-spec, to-tickets, implement-spec, triage, code-review or ask-matt in a repo.

What you get

An ## Agent skills block in CLAUDE.md or AGENTS.md, plus docs/agents/issue-tracker.md, domain.md and maybe triage-labels.md.

Why It Exists

The Skills Ask “Which Tracker?” So Answer Once

1

Scaffold the per-repo configuration that the engineering skills assume:

2

When the installer asks which skills to take, include setup-matt-pocock-skills.

3

Mention they can edit docs/agents/*.md directly later; re-running this skill is only necessary if they want to switch issue trackers or restart from scratch.

Mental Model

Explore, Recommend, Confirm, Write

Explore

Read whatever exists; don't assume:

Ask

One section, one answer, then the next.

Skip

skip the section entirely when exploration already settled it

Write

Never create AGENTS.md when CLAUDE.md already exists (or vice versa); always edit the one that's already there.

Gotchas

Prompt-Driven Means You Review The Draft

From reading every file at 5beb35b. No scripts ship, and it was not run against a live repo.

Gap ready-for-agent without triage

to-spec and to-tickets always apply ready-for-agent, but this skill only writes or creates labels when triage is installed.

Gap Sub-issues only on GitHub

The GitLab and local tracker docs have no sub-issue operation, though to-tickets asks for one.

Cost GitLab blocking needs Premium

Native blocking links are a Premium/Ultimate feature

Gap skills.sh needs Node 22.20+

Running npx skills@latest add --help on the box (Node 20.19) crashed: skills 1.7.4 requires node ≥22.20.0. The README does not say so.

Copy Never picks AGENTS.md vs CLAUDE.md for you

It edits whichever exists and asks when neither does.
